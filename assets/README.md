# Viewer demo

`demo.gif` and `demo.mp4` show a screen recording of the AgentMemory 0.9.31 viewer at 3× speed, with dark and light themes. The website uses the same GIF at `website/public/demo.gif`.

The recording uses fictional `atlas-web`, `support-api` and `docs-site` projects in an isolated data directory, with every runtime feature flag enabled. Embeddings run locally. A deterministic local model fixture supplies synthetic compression responses.

The tour covers the overview, memories and versions, crystals, graph relationships, sessions, actions, replay and activity.
