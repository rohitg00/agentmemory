# Viewer demo

`demo.gif` and `demo.mp4` show the AgentMemory 0.9.31 viewer running in Chromium. The website uses the same GIF at `website/public/demo.gif`.

The recording uses fictional `atlas-web`, `support-api` and `docs-site` projects in an isolated data directory, with every runtime feature flag enabled. Embeddings run locally. A deterministic local model fixture supplies synthetic compression responses.

The tour covers live updates, memory search and provenance, lessons, crystals, the knowledge graph, sessions, actions, replay, activity, project profiles, health, audit history and both themes.
