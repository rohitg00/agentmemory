
## 2. 数据流流程

```
用户操作 → Claude Code → Hook捕获 → Worker处理 → iii-engine存储
     ↑                                                      │
     └──────────── 查询结果 ← MCP工具调用 ←──────────────────┘
```

## 5. 与 Claude Code 的集成点

```
┌─────────────────────────────────────────┐
│           Claude Code 生命周期           │
├─────────────────────────────────────────┤
│                                         │
│  SessionStart ──▶ 可选: 注入历史上下文   │
│       │                                │
│       ▼                                │
│  ToolUse ──▶ 执行工具 (Read/Edit/Bash) │
│       │                                │
│       ▼                                │
│  PostToolUse ──▶ Hook 捕获 ──▶ Worker  │
│       │                                │
│       ▼                                │
│  PreToolUse (下一次) ──▶ 可选: 注入记忆  │
│       │                                │
│       ▼                                │
│  SessionEnd ──▶ 触发总结 + 图谱提取      │
│                                         │
└─────────────────────────────────────────┘
```
